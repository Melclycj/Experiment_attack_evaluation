# 3.1 判定忠实 — 攻击清单

**本文件。** 本单元的攻击，每行一个，是这些攻击的唯一出处。怎样测、怎样判见 [tests.md](tests.md)；差分随机测试等不是攻击的检验见 PLAN，共用规定见 [METHOD](../METHOD.md)。本单元的不设防配置按规则 3 是现状：直接连网，不经代理，要经 engine 的手法在这里退化成直接做成目标。ZTAC 攻击的筛选与改写理由在 README 第 2 节；"冒用研究包"指 2026-09-27 冒用研究包 step-02 的案例证据。本单元管 engine 是否忠实执行已作出的判定；某个目的地该不该准本身是策略，交给 PDP（[METHOD](../METHOD.md) 规则 10），代表在 README 第 3 节演示。

**每条先判出发点（用户 2026-11-04 批准）。** 每个攻击先问：本文设定里，这个攻击的出发点真的出得了吗？设定是：攻击者是隔间里以本行 uid 运行的任意代码，持有本行代理口、控制口一端与隔间内前端，碰不到判定口、管理口、hook 口、凭据库与正文 memfd；改表、答复、撤销只有用户经管理客户端能做；兜底条目放行任意主机任意端口的无账户 GET，所以攻击者自己的服务器经兜底可达；主机名在批准之后才由 connector 解析。判的结果：13 个编号保留实测，2 个改写成结构论证，2 个并入 DF-03；报的攻击数从 17 改为 13。DF-14 另判：v4 建了经 engine 只读的宿主文件，但被读的对象不进隔间、攻击者换不了，改写成结构论证（用户 2026-11-06），不计入这 13 个。和 ZTAC 并排比较时，改写与并入的 4 个仍按原攻击对应，标"没有入口"或"并入哪一条"。

## 不写攻击的（结构论证）

依 METHOD 规则 11"没有入口"一类：被攻击的对象从不进隔间，实验只能演示找不到接口；依据是设计与读码（METHOD 规则 11）。

- **DF-02 批准之后改正文。** 正文由 connector 写进它自己建的 memfd，加禁写、禁改长度三道封后随帧交核心；核心核对三道封都在，缺一即拒；connector 从自己内存里的那份发出，不再从前端读（agent-rm-model 4.2、4.3；K-24、C-13）。隔间没有这个 memfd 的句柄，攻击者能做的只是在同一条代理口连接上再发字节，那是下一个请求，要在前一个响应结束后才被读（C-04）。同一理由覆盖 DF-08、DF-10 的换正文一半。连带：这是 2.2 唯一的攻击，2.2 不再有攻击。
- **DF-14 读宿主路径时把目录换成 symlink，或批准后改指别的文件。** v4 建了经 engine 只读的宿主文件，但被读的对象攻击者碰不到。对象是用户经管理口登记的、工作区之外的目录或文件；登记时，路径落在任何工作区的存储里即拒（engine/fileobjects.py 的 check_not_engine_owned）。隔间根是新 tmpfs，里面没有宿主路径；MCP server 的三个工具只有列出对象、列目录与读，没有写（agent-rm-model 3.3"经 engine 读的路径"；validation H-04）。隔间里的代码影响宿主文件只有一条路，就是工作区导出。导出只把提交取进 refs/remotes/agent-<工作区>/*，不动用户的工作树（A-08）；非 git 导出不收符号链接（A-09）。所以隔间里的代码换不了目录，也放不进 symlink。宿主上别的进程去换，不在攻击者模型里。即使有人换了，打开时也是从登记目录的 fd 往下解析，带 RESOLVE_BENEATH、RESOLVE_NO_SYMLINKS、RESOLVE_NO_MAGICLINKS（native/sandbox/support.c 的 w2_open_beneath；H-10）；重开锚点时还会核对 device 与 inode（H-03）。代码取 v4（engine-v3 @ a9eff999）。
- **DF-15 填别行的调用编号。** 规范形式里没有 agent 能填的调用编号；序号由 connector 在本进程内分配，核心按消息从哪个判定口进来认定行（agent-rm-model 4.2 的字段清单；K-01、K-36）。请求里多一个字段，整帧按文法拒，这是输入解析，归 2.2。
- **DF-16 的判定口一半。** 判定口是 spawner 起 connector 时交给它的 socketpair，在 connector 与核心之间，不进隔间（agent-rm-model 4.2）。

**不在本清单。** 过期答复（原 DF-13：允许帧在客户端断开或超时之后才到）与崩溃（写记录与发出请求之间崩溃）不是攻击，移交 engine 第二阶段第 3 步的测试。
