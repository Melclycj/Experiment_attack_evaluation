# preservation — G2 receive and check

Scope: the ten transitions 02 §7 assigns to G2 (T-20, T-21, T-22, T-23, T-24, T-25, T-26, T-60, T-63,
T-64) against I = I_acc ∧ I_state of 03 §1, from any state in which I holds. None of these transitions
writes a state variable that I_state ranges over (lease state, row state, expected_uid, membership set,
empty fact and basis, channel installation, engine epoch): the G2 transitions queue an skb (T-20, T-60,
T-64), read and compare (T-21, T-22, T-23), accept — the one D-ACC of the model — (T-24), gate (T-25),
write outbound (T-26) or move a descriptor (T-63). Each row therefore argues two things: that the
transition leaves I_state as it found it, and, for T-24, that the newly accepted bytes satisfy I_acc by
03 §4 part (1). Refusal outcomes hand a trigger to T-40 or T-46, which are G4 transitions cited here as
Step 1 facts only; the CLOSED landing of those triggers is G4's row. Source abbreviations follow 01;
"the row" is the Session/Execution pair reached through the Channel object the bytes arrived on.
