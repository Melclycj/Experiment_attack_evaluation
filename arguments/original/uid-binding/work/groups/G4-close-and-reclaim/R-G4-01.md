# R-G4-01 — A's old task survives a reported-empty/release cycle and speaks under a uid now assigned to B.

## 1 What the adversary does
A's old task survives a reported-empty/release cycle and speaks under a uid now assigned to B.

## 2 How it would produce false attribution
- **Preconditions:** execution A reached at least T-05 and T-07, so tasks at the pool uid u exist inside
  P_XA; A's row became CLOSED by any trigger (T-40); an empty fact for A was recorded (T-43, or T-14's
  local basis); the lease was released (T-45); execution B was reserved for the same workspace and took the
  same numeric u under a new execution_id, session_id, channel_id and lease_id (T-01, a G1 fact); at some
  instant t inside J_B a task of A — PID 1, a forked descendant, a thread — is alive with real kernel uid u;
  and A's bytes reach B's endpoint. The last item is stipulated as A-07 (a held foreign descriptor), because
  without it A's survivor can write only into A's own channel, whose row is CLOSED and is never read
  (03 §5.4 run 2c; 02 §4.1 item 1): descriptor possession alone is not the failure predicate, and the
  survivor alone is not a route either — both are needed. Configuration: all three (C-LS, C-LP, C-R) under
  the common abstraction of the frozen revision; the agent ↔ engine leg is identical in each.
- **Transitions traversed:** T-01 … T-11 for A (launch, G1 facts); an exit or close trigger — T-65, T-46,
  T-47, T-48 or a deadline — into T-40; T-41 (stop), T-42 (PID 1 exit), T-43 (execution_empty) or the
  local basis of T-14; T-45 (release); T-01 … T-09 for B (G1 facts); T-20 (a) by A's survivor into B's
  channel; T-21 … T-24 at B's row (G2 facts) ending in a D-ACC labelled B.
- **Sufficient condition violated:** C-06 p62, cell D_62 with q24 (the offending task belongs to a prior
  allocation for this uid and survives into J_B): at the send instant t ∈ J_B a task with real uid u exists
  that is not a member of P_XB. The kernel stamps u (T-20 (a)); B's row has expected_uid = u, so the per-
  fragment comparison passes (C-02 … C-04 hold); the label read at D-ACC is A_B's (C-05 holds); but
  Exec(b) = A, since the sending task is in P_XA. The label names B, the ground-truth execution is A — a
  wrong attribution with every check fact intact. The 03 run-2b trace realises this history inside the
  bounded subset once the membership half of the gate is removed, T-01's and T-03's reuse checks are not
  encoded and A-07 is stipulated.

## 3 What stops it
T-45 releases the lease only after T-43's empty fact, whose pid1_reaped basis follows the kernel's namespace
zap (T-41/T-42) and whose never_created basis follows the spawner's seal against clone; errors and timeouts
quarantine (T-44) and never free — realized in the prototype engine and spawner and checked. The cut is at
T-45: its precondition is row CLOSED ∧ close step 2 done (01 v9 T-45) ∧ membership_empty ∧ old callbacks
bound, and membership_empty can only be written from a basis that is sound at its source (IG-03, IG-04).
Each history in which A's task could be alive at release is cut by a row of this group's preservation file,
and each row's engine or spawner side now has a realization in the prototype:

- A descendant or sibling outlives PID 1 — T-41 and T-42 rows: zap_pid_ns_processes forbids new pids,
  SIGKILLs every remaining member and waits until every other pid is freed before PID 1 becomes reapable,
  covering outside-parent and ptraced tasks (IG-05; EV-17, EV-18). The prototype spawner is the only reaper:
  SIGCHLD stays SIG_DFL and the one waitpid on a record's PID 1 is the only source of pid1_reaped (EV-206).
- A false never_created — T-43 row: the spawner reports never_created only for a record with no child pid,
  and a stop or failure marks the record stopping before that report, after which no clone is attempted
  (EV-206; val row 209; the clone refusal itself is the guard at the head of clone_ready, read for this
  file, see section 6). The engine matches a fact by execution, lease and epoch and faults on a fact for an
  unknown execution, a changed lease or a row never submitted (EV-218); the only uid-keyed table is the
  allocator's (EV-196). A never_created after a prepared record that names a child faults (EV-203).
- A false local basis — T-40 step 4 with T-02 and T-14 as G1 facts: local_never_submitted is written only
  after the queued spawn is withdrawn, which can happen only before any send; an uncertain send is never
  local and ends with the lease quarantined (EV-205, EV-221).
- Release without a fact — T-44 and T-45 rows: membership_empty is assigned at exactly two places, and the
  lease is released only when the row is CLOSED, membership_empty, close step 2 has run and the lease is
  HELD, once (EV-205); a kill error and a kill with no effect quarantine and the uid is not reused (EV-204);
  a wait error is a reap failure plus control loss, never empty (EV-206); a quarantined lease is lifted only
  by a later real empty fact while the control link is healthy (EV-203); the engine reads /proc only for its
  own start-up readings and status (EV-205 note).
- Control loss — T-49 row: on control loss every row is set CLOSED, each unconfirmed lease quarantined, and
  the engine exits; the build accepts no new spawner (EV-216, EV-217). The new-epoch variant (a survivor
  across epochs) is R-GX-04, not this route — an unreleased lease of a lost epoch keeps its interval open for
  the cell assignment, so that history is D_61 ∧ q33 (03 §1.1 (iii), version 4).
- Exit timing — T-65 row: a send before the exit is attributed live-at-send to A at A's row (J_A still
  open); it is not this route, which needs a send inside J_B.
- Nothing keeps the namespace alive past the fact: neither engine nor spawner enters, traces or holds a
  descriptor into an execution's namespace (EV-235, the realization of EV-19).

Two further gates in the frozen text act on the same facts and are not relied on here: T-01's precondition
that the previous lease satisfied CLOSED AND empty (rr L560–561) and T-03's refusal of a uid or lease still
occupied in the spawner's records (conn L112). Both are now realized (EV-200; EV-207, EV-209), and a
quarantined lease stays among the allocator's holders (EV-200). Both are G1's transitions; under this
route's premises T-45 alone leaves no live task at u when the lease becomes free (T-45 row, IG-02).
