Linux seccomp (secure computing mode) is a kernel feature that restricts which system calls a process can make, reducing the attack surface if that process is compromised. A process can enter a restricted "strict" mode that allows only a few calls, or install a custom filter (a classic BPF program, "seccomp-bpf") that allows, denies, logs, or kills based on the call number and its arguments. Container runtimes, browsers, and sandboxes like Docker and Chromium use it to limit what untrusted code can ask the kernel to do.
