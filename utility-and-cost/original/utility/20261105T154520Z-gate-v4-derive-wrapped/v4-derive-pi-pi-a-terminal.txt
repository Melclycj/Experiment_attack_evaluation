Linux seccomp (secure computing mode) is a kernel feature that restricts which system calls a process is allowed to make. Originally it offered a strict mode that permitted only a few calls like read, write, and exit, but the seccomp-bpf extension lets a process install a BPF filter that allows, denies, traps, or logs each syscall based on its number and arguments. This reduces the kernel attack surface available to a process, which is why sandboxes and container runtimes such as Docker use it.
