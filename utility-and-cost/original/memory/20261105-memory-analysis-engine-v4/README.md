## 读的时候要带上的

- **Docker Sandboxes 只有 2 次重复。** 第二遍起步时 sbx 的登录被服务端吊销（refresh token revoked，"Not authenticated to Docker"），那一遍一档都没测，记为 pass_error；第一遍两次都在。它是本轮的 VM 型对照，各档与前两轮的跨轮比较见下一条。
- **跨轮漂移**（drift-hypothesis.txt）：本轮 bare-api-only 每单位 1 档 179.6–182.6，与 10-31 上午那轮（180.4–181.8）相同、比 10-30 与 10-31 晚那轮（187.1–187.5、186.5–187.3）低约 5–7；2–16 档与各轮相差 0 到 2.9，16 档不超过 0.5。Docker Sandboxes 非共享额外：1 档 1494.3–1499.5，落在 10-30 那轮的范围（1481.5–1517.1）里、比 10-31 晚那轮（1480.0–1489.7）高 5–20；2、4 档与两轮重叠或相差不到 5；8 档本轮下端 996.1 比两轮（1005.4–1007.9）低约 9–12；16 档 921.1–927.1 比两轮（926.1–929.3）低 0–8。
- **假设甲（协议第 7 节）**：本论文三次中最大的值，对 min(250, 每个 VM 型对象最小值 / 4)。共享放法每档对三家都满足（16 档 32.7 对 Docker Sandboxes 230.3、Gondolin 173.4、Kairos 119.2）。副本放法对 Docker Sandboxes 与 Gondolin 每档满足，对 Kairos 在 8、16 档不满足（123.8 对 120.0、128.8 对 119.2），1、2、4 档满足（4 档 113.7 对 118.3）；所以副本放法下假设甲不成立。Gondolin 与 Kairos 只在 10-31 晚那轮测过，这部分比较跨轮；那轮的 bare-api-only 在 8、16 档与本轮相差不到 1 MiB，小于副本放法超线的 3.8 与 9.6。没有做统计检验，每档 3 次重复。
- **E-09（e09-passes.json）**：两个对象各两次核心运行。第一遍删掉 16 个工作区的默认兜底（deleted），第二遍已不在（absent），每个工作区 4 条。每遍的模型检查都是 POST /v1/messages 放行、凭据已放、上游 200。93 个常驻行里，每个 Claude Code 启动时只发三个请求：GET settings（404）与 GET policy_limits（200）放行、凭据已放，downloads.claude.ai 被精确拒绝；空载的 k6 行没有请求。落到其余主机而被拒的请求 0 个；提问 0 个。
- **全部常驻屏幕**（93 + 93 + 93 + 62）都在提示符、auto mode。单位构成：每个常驻行隔间里是 claude、engine-frontend、engine-mcp、w2-relay，隔间外 connector 与文件 worker 各一个；有 5 次在起行那一刻多看到一个短命的 claude 子进程（判活按进程自己的 cgroup 清点，没有误判）。
- **常驻读数在台阶之后**（step_and_core.py → step-and-core.txt，读法同 runs/20261101-checks-resident-step-and-model-api）：本论文两行与 bare-api-only 每次都看得到 Claude Code 约 2 分钟时每 agent 15–18 MiB 的下降，最后一次偏离在等待开始后 116–122 秒，等待 150 秒。Docker Sandboxes 4–16 档同样（112–117 秒）；1、2 档有 3 次不明显或偏晚（最后一次偏离 124–153 秒），读数窗口内变化不到 4 MiB，都没被标不稳定。
- **共用组里核心的累积**（同一个脚本）：建单位之前没有行在线时的共用组 PSS，从每次核心运行开始的约 26 MiB 涨到起过 93 行后的约 90 MiB；对起过的行数拟合，第一遍每行约 0.7 MiB、第二遍约 1.06 MiB。10-31 那轮约 0.6。所以"共用部件每多一个 agent 涨约 4.4"大半是档位从小到大测积下来的历史，不全是在线 agent 的成本；这一轮第 2 次重复起过的行更多，16 档共用组因此是 107–109，另两次 88–91。
- **核心与共用部件的固定成本**（基准 2 减基准 1）对 engine 两行没有意义：两次基准之间建过部署、起过模型检查行；只看共用组自身的 PSS。
- **只测了一台机器**（AWS m8i.4xlarge，嵌套虚拟化），只测了"停在提示符"这一种负载；每档 3 次重复，范围是配对范围。
